# Configuration Reference

Ontofelia uses a single JSON5 configuration file located at `~/.ontofelia/ontofelia.json5`. This file is created during `ontofelia onboard` and can be edited manually or via CLI commands. Missing keys fall back to the defaults below (the schema lives in `packages/config/src/schema.ts`).

## File Location

| Platform | Default Path |
|----------|-------------|
| Linux/macOS | `~/.ontofelia/ontofelia.json5` |
| WSL | `~/.ontofelia/ontofelia.json5` |

The config directory also contains (see [Data Directory Layout](#data-directory-layout)):
- `auth.json` — OAuth tokens (created by `ontofelia auth login`)
- `agents/` — per-agent session database and transcripts
- `triplestore/` — knowledge graph data (embedded Oxigraph by default)
- `workspace/` — agent workspace files

## Complete Configuration Schema

All values shown are the defaults.

```json5
{
  version: 1,                       // Config schema version

  // Gateway settings
  gateway: {
    host: "127.0.0.1",
    port: 18780,                    // HTTP/WebSocket port
    bind: "loopback",               // "loopback" | "lan" | "tailnet" | "custom"
    token: "",                      // Auth token (generated by `ontofelia onboard`)
    auth: {
      tokenRequired: true,          // Enforce Bearer auth on /api/* and /ws
      allowQueryToken: false        // Allow ?token= on the WebSocket URL
    }
  },

  // Canvas host (media/file serving)
  canvasHost: {
    enabled: true,
    port: 18793,
    pathPrefix: "/__ontofelia__/canvas/"
  },

  // Agent configuration
  agents: {
    defaults: {
      workspace: "~/.ontofelia/workspace",  // Bootstrap files (SOUL.md, IDENTITY.md, USER.md, ...)
      model: "provider/model",              // Falls back to provider.defaultModel
      mediaMaxMb: 8,
      heartbeat: {},
      sandbox: {
        scope: "off",               // "off" | "agent" | "session"
        workspaceAccess: "rw",      // "none" | "ro" | "rw"
        // containerImage: "...",   // Optional custom Docker image
        memoryLimitMb: 512,
        cpuQuota: 100000,
        network: false
      }
    },
    list: []                        // Additional agent definitions
  },

  // Message routing (reserved)
  routing: {
    agents: {}
  },

  // Channels (all optional; webchat is always available and needs no config)
  channels: {
    telegram: {
      enabled: false,
      token: "",                    // Bot token from @BotFather
      allowedChats: [],             // Allowed Telegram chat IDs
      // ownerChatId: "..."
    },
    discord: {
      enabled: false,
      token: "",                    // Bot token from Discord Developer Portal
      // guildId: "..."
    },
    matrix: {
      enabled: false,
      // homeserverUrl: "...",
      // accessToken: "..."
    }
  },

  // Message context handling
  messages: {
    maxContext: 20,                 // Max messages sent to the LLM
    truncateAt: 4000                // Truncate individual messages at N characters
  },

  // Session policy
  session: {
    maxHistory: 50,
    pruneAfterDays: 90,
    scope: "per-channel-peer"       // "main" | "per-channel-peer"
  },

  // Chat command handling
  commands: {
    prefix: "/",
    allowAdminOnly: false
  },

  // Tool and security policy
  tools: {
    allow: [],                      // Explicitly allowed host-only tools, e.g. ["exec"]
    deny: []                        // Explicitly denied tools
  },
  plugins: {
    trusted: [],                    // Plugin names explicitly trusted for activation
    allowUntrusted: false           // Development-only escape hatch
  },
  security: {
    requireGuardian: true,          // Require operator approval for guarded tool calls
    guardianTimeoutMs: 60000
  },

  // Semantic Memory
  memory: {
    backend: "oxigraph",            // "oxigraph" (default, embedded) | "fuseki" (legacy sidecar) | "memory" (no persistence)
    triplestore: {
      type: "embedded",             // "embedded" | "sidecar" | "remote"
      dataDir: "~/.ontofelia/triplestore",
      port: 18787,                  // Sidecar (Fuseki) port
      endpoint: "http://127.0.0.1:18787/ontofelia"
    },
    reasoner: {
      enabled: true,
      profile: "OWL_DL",            // "RDFS" | "OWL_DL" | "OWL_FULL"
      mode: "on-write",             // "on-write" | "periodic" | "manual"
      periodicIntervalMinutes: 60
    },
    ontology: {
      autoEvolve: true,             // Allow schema evolution proposals
      requireApproval: false,       // Require manual approval of proposals
      maxVersions: 50
    },
    reflection: {
      enabled: true,
      cron: "0 3 * * *",            // Nightly reflection run
      targetChannel: null           // Channel to notify with reflection results
    },
    provenance: {
      enabled: true,
      trackConfidence: true,
      trackSource: true
    },
    sparqlExposed: false            // Expose raw SPARQL to the agent
  },

  // LLM Provider
  provider: {
    name: "mock",                   // "openrouter" | "openai" | "openai-codex" (OAuth) | "mock"
    // apiKey: "sk-...",            // API key (not needed for OAuth or mock)
    // baseUrl: "...",              // Custom API base URL
    defaultModel: "mock",
    aliases: {},                    // Model shortcuts, e.g. { fast: "deepseek/..." }
    // maxTokens: 4096,
    // temperature: 0.7,
    // timeout: 30000,
    autoFallback: true,             // Retry with fallback models on empty response
    fallbackModels: []              // Ordered fallback list (built-in free models used when empty)
  }
}
```

> **Note:** A few sections are accepted by the schema but not yet honored by the runtime: `messages`, `routing`, `commands`, and `session.scope` currently run on their built-in defaults regardless of what you configure. They validate fine; they just have no effect yet.

## Environment Variables

These override config file values at load time:

| Variable | Description |
|----------|-------------|
| `ONTOFELIA_TOKEN` | Gateway auth token |
| `ONTOFELIA_PORT` | Gateway port |
| `ONTOFELIA_BIND` | Bind mode (`loopback`, `lan`, `tailnet`, `custom`) |
| `OPENAI_API_KEY` | OpenAI API key (used when `provider.apiKey` is unset) |
| `OPENROUTER_API_KEY` | OpenRouter API key (used when `provider.apiKey` is unset) |

The config directory itself is always `~/.ontofelia` (derived from the home directory of the user running the gateway).

## Provider Configuration Examples

### OpenRouter (Recommended for Getting Started)

```json5
provider: {
  name: "openrouter",
  apiKey: "sk-or-v1-...",
  defaultModel: "deepseek/deepseek-chat-v3-0324:free"
}
```

### OpenAI (API Key)

```json5
provider: {
  name: "openai",
  apiKey: "sk-...",
  defaultModel: "gpt-4o-mini"
}
```

### OpenAI (OAuth / ChatGPT Plus)

No API key needed — run `ontofelia auth login` (or pick the OAuth option in `ontofelia model`) and authenticate in your browser. The token is stored in `~/.ontofelia/auth.json`.

## Session Policies

| Scope | Behavior |
|-------|----------|
| `main` | One global session for the agent |
| `per-channel-peer` | One session per sender per channel (default) |

## Data Directory Layout

```
~/.ontofelia/
├── ontofelia.json5           # Configuration
├── auth.json                 # OAuth tokens (created by `ontofelia auth login`)
├── gateway.pid               # PID file while the gateway runs in background mode
├── pairing.db                # Channel pairing/allowlist database
├── agents/
│   └── ontofelia/
│       └── sessions/
│           ├── sessions.db   # SQLite session index
│           └── transcripts/  # JSONL chat transcripts
├── triplestore/
│   └── oxigraph/             # Embedded RDF triplestore (default backend)
│                             # (Fuseki backend data lives under triplestore/ as well)
├── ontology/                 # Ontology versions and proposals
├── workspace/
│   ├── SOUL.md               # Agent personality and behavior
│   ├── IDENTITY.md           # Agent identity card
│   ├── USER.md               # User preferences
│   └── ...                   # AGENTS.md, TOOLS.md, BOOTSTRAP.md
├── media/                    # Uploaded files and thumbnails
├── scheduler/                # Cron job and webhook definitions
├── backups/                  # Knowledge graph backups
├── logs/                     # Gateway logs (background mode)
├── skills/                   # Custom skill definitions
└── plugins/                  # Plugins copied here by `ontofelia plugins install`
```
